🎓 UKK MTsDU

«A modern school management dashboard built as a practical web development project.»

UKK MTsDU adalah project website untuk kebutuhan pengelolaan dan monitoring data sekolah, dibuat sebagai bagian dari proses belajar dan pengembangan skill web development.

Project ini memiliki beberapa sisi pengguna, mulai dari halaman utama hingga dashboard untuk admin dan murid.

🔗 Live Demo: "ukk-mtsdu.vercel.app" (https://ukk-mtsdu.vercel.app)

---

✨ Features

👨‍💼 Admin

- Admin login
- Dashboard admin
- Cek data kelas
- Kelola kelas
- Kelola nilai
- Rekap data

👨‍🎓 Murid

- Dashboard murid
- Tampilan informasi yang lebih sederhana
- Akses data sesuai kebutuhan pengguna

🎨 Interface

- Responsive layout
- Modern dashboard UI
- Interactive navigation
- Structured pages
- Custom CSS & JavaScript

---

🛠️ Built With

- HTML5 — Struktur halaman
- CSS3 — Styling & responsive design
- JavaScript — Interaksi dan logic
- Vercel — Deployment

🎯 Project Purpose

Project ini dibuat bukan hanya untuk menghasilkan sebuah website, tetapi juga sebagai bagian dari proses belajar dalam memahami bagaimana sebuah website dengan beberapa halaman dan role pengguna dapat disusun.

Beberapa hal yang saya pelajari dari project ini:

- Membuat struktur website yang lebih terorganisir
- Membuat dashboard berdasarkan role pengguna
- Mengatur navigasi antar halaman
- Mengembangkan UI menggunakan CSS
- Menggunakan JavaScript untuk interaksi
- Membuat project yang siap di-deploy
